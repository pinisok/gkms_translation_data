# Web translation text

This repository belongs to the new web text pipeline.

Payload: `local-files/` and `version.txt`. Each release is tagged with `version.txt` and carries
`<repository>-<version>.zip` (the legacy `local-files/` + `version.txt` layout) and `SHA256SUMS`.

The legacy GakumasTranslationDataKor repositories and their workflows are separate.
